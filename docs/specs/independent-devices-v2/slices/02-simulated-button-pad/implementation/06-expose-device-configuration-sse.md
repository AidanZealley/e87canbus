# Workstream 6: Expose device configuration over SSE

Status: not started.

## Task packet

### Outcome

An authenticated button pad can open the production configuration endpoint and receive Workstream
5's current durable envelope followed by complete replacements using the approved SSE and deployment
contract.

### Scope

- Add `GET /api/devices/configuration` with `text/event-stream`, `Cache-Control: no-store`, one
  single-line JSON `data` field per record, blank-line termination and idle comments.
- Authorize only supported device roles. In this slice that means button pad; console, operator,
  unauthenticated and Servotronic principals are rejected.
- Read identity only from `request.state.principal` and delegate current/replacement ownership to the
  accepted Workstream 5 service.
- Ensure failed sends and request disconnects unregister the subscriber and do not leak route tasks.
- Add the exact nginx location needed for unbuffered device configuration SSE while retaining
  certificate headers and the existing optional-client-certificate server behavior.
- Model the complete button-pad envelope as the endpoint's SSE response and regenerate OpenAPI and
  Hey API artifacts from source.

### Non-goals

- Another publisher, repository access from the route, replay, `id`, `Last-Event-ID`, presence or
  browser consumption.
- A shared generic SSE router/framework or modifications to the coordinator browser stream.
- Servotronic configuration or simulator composition.

### Initial ownership

- the device configuration route, Workstream 1 document model and Workstream 3 envelope model
- `hosts/src/e87canbus/api/auth.py` for the exact GET permission
- `hosts/src/e87canbus/api/main.py` for router inclusion only
- `deploy/nginx/e87canbus.conf`
- focused route, authorization, deployment and OpenAPI tests under `hosts/tests/`
- `protocol/openapi.json` and generated coordinator client artifacts under
  `frontend/packages/coordinator-client/`, regenerated by the repository command

Integration exception: adjust Workstream 5's public subscription signature only if real ASGI
cancellation exposes a defect, and return the change through the orchestrator. Do not change its
durability rules silently.

### Required seams

- The first `data` record comes from the subscription's atomic current envelope; the route does not
  fetch another snapshot or database row.
- Keepalive comments are bytes for the device receive watchdog only. They do not write status,
  update presence or advance generation.
- The outer request task is cancelled or unwound when the accepted service disconnects a saturated
  consumer, matching Starlette's actual streaming task behavior.
- Nginx disables buffering only for this stream and passes the same trusted certificate metadata as
  other routes. Application authorization remains authoritative.
- OpenAPI exposes the real button-pad envelope under `text/event-stream`; no browser-specific live
  union is imported.

### Acceptance criteria

- A valid button-pad principal receives `200`, the exact headers and its complete envelope first.
- Console, operator, unauthenticated, unknown-role and Servotronic requests cannot open the stream.
- Complete replacements arrive as one-line JSON SSE records, and idle comments arrive within the
  approved device receive-watchdog interval.
- No event ID or replay state exists, and reconnect starts from Workstream 5's current durable value.
- Slow-client disconnection and application shutdown close the real ASGI request without leaking a
  subscriber or task.
- Production operation coverage equals the closed permission table; nginx, served/exported OpenAPI
  and generated-contract checks pass.
